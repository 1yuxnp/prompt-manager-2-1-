# 나만의 프롬프트 관리 프로그램

Python으로 만든 콘솔 기반 프롬프트 관리 프로그램입니다.

자주 사용하는 프롬프트를 저장하고 카테고리별로 조회하거나 검색할 수 있으며, 자주 사용하는 프롬프트를 즐겨찾기로 관리할 수 있습니다.

## 개발 환경

- Python 3.14.7
- Visual Studio Code
- Git
- GitHub

## 실행 방법

터미널에서 다음 명령어를 입력합니다.

```bash
python main.py
프로그램이 실행되면 메뉴 번호를 입력하여 원하는 기능을 사용할 수 있습니다.

주요 기능
프롬프트 추가
프롬프트 목록
카테고리별 조회
프롬프트 검색
프롬프트 상세 보기
즐겨찾기 관리
즐겨찾기 목록
프로그램 종료
프롬프트 데이터

각 프롬프트는 다음 정보를 포함합니다.

제목
내용
카테고리
즐겨찾기 여부
카테고리
텍스트 생성
이미지 생성
영상 생성
페르소나
자동화
기타
Git 관리

Git을 사용하여 기능별로 변경사항을 커밋하고 코드의 변경 이력을 관리했습니다.

별도의 브랜치를 생성하여 기능을 개발한 후 main 브랜치에 merge했습니다.

프로젝트 구조

prompt-manager/
├── main.py
├── README.md
└── .gitignore
