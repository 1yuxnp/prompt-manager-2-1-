# 나만의 프롬프트 관리 프로그램

Python을 활용하여 자주 사용하는 프롬프트를 관리할 수 있는 콘솔 프로그램입니다.

프롬프트를 카테고리별로 조회하고 키워드로 검색할 수 있으며, 자주 사용하는 프롬프트를 즐겨찾기로 관리할 수 있도록 구현했습니다.

## 개발 환경

- Python 3.14.7
- Visual Studio Code
- Git 2.55.0
- GitHub
- Windows

## 실행 방법

### 1. 저장소 Clone

```bash
git clone https://github.com/1yuxnp/prompt-manager-2-1-.git
```

### 2. 프로젝트 폴더 이동

```bash
cd prompt-manager-2-1-
```

### 3. 프로그램 실행

```bash
python main.py
```

## 주요 기능

### 1. 프롬프트 추가
새로운 프롬프트의 제목, 내용, 카테고리를 입력하여 저장할 수 있습니다.

### 2. 프롬프트 목록
저장된 모든 프롬프트를 번호와 함께 확인할 수 있습니다.

각 프롬프트의 제목, 카테고리, 즐겨찾기 여부를 확인할 수 있습니다.

### 3. 카테고리별 조회
카테고리를 선택하여 해당 카테고리에 등록된 프롬프트만 확인할 수 있습니다.

### 4. 프롬프트 검색
검색어를 입력하여 프롬프트의 제목 또는 내용에 포함된 키워드를 검색할 수 있습니다.

### 5. 프롬프트 상세 보기
프롬프트 번호를 선택하여 제목, 내용, 카테고리, 즐겨찾기 여부 등 상세 정보를 확인할 수 있습니다.

### 6. 즐겨찾기 관리
프롬프트를 즐겨찾기에 추가하거나 해제할 수 있습니다.

### 7. 즐겨찾기 목록
즐겨찾기로 설정한 프롬프트만 모아서 확인할 수 있습니다.

### 8. 잘못된 입력 처리
메뉴에서 잘못된 번호를 입력하면 안내 메시지를 출력하고 다시 메뉴를 선택할 수 있도록 구현했습니다.

## 프롬프트 카테고리

프로그램에서는 다음과 같은 카테고리를 사용합니다.

- 텍스트 생성
- 이미지 생성
- 영상 생성
- 페르소나
- 자동화
- 기타

## 기본 등록 프롬프트

프로그램 시작 시 이전 미션에서 작성한 프롬프트가 기본 데이터로 등록되어 있습니다.

예시:

- Term Cafe UI 생성
- COOL SPOT 광고 이미지
- ExamPilot 학습 계획

## 데이터 구조

프롬프트 데이터는 리스트와 딕셔너리를 사용하여 관리합니다.

각 프롬프트는 다음 정보를 포함합니다.

- 제목
- 내용
- 카테고리
- 즐겨찾기 여부

예시:

```python
prompts = [
    {
        "title": "Term Cafe UI 생성",
        "content": "카페 음료 주문 앱 UI를 생성해주세요.",
        "category": "이미지 생성",
        "favorite": False
    }
]
```

## Git 관리

프로젝트 개발 과정에서 Git과 GitHub를 사용하여 코드의 변경 이력을 관리했습니다.

기능별로 작업 내용을 나누어 커밋했으며, 별도의 브랜치를 생성하여 프롬프트 목록 기능을 개발한 후 `main` 브랜치에 병합했습니다.

### 사용한 Git 명령어

```bash
git init
git add
git commit
git push
git pull
git clone
git checkout
git merge
```

총 10개 이상의 의미 있는 커밋을 작성하여 기능별 변경 이력을 관리했습니다.
